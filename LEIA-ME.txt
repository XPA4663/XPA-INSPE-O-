XPA · Inspeções e Manutenção — aplicativo único (PWA offline)

Módulos incluídos nesta versão (8):
  🌡️ Inspeção termográfica (NETA Tab. 100.18)
  🏭 Manutenção preventiva de subestação (AT/MT/BT, proteção, aterramento, civil – com ensaios)
  👁️ Inspeção visual de subestação (mesmos checklists, sem ensaios)
  🔋 Inspeção de grupo gerador (motor, alternador, QTA; isolamento IP/DAR, ôhmica, teste em carga)
  ⚙️ Inspeção de motores elétricos (isolamento, ôhmica, corrente, temperatura, vibração)
  🌩️ Laudo de SPDA (NBR 5419 – captação, descidas, aterramento, DPS; resistência e continuidade)
  🦺 Laudo / auditoria NR-10 (prontuário, medidas de controle, instalações, EPI/EPC, emergência)
  🧰 Visita técnica (constatações por item, fotos, prioridade, recomendações para proposta)

Arquivos (enviar TODOS para a raiz do repositório):
  index.html, mod-termo.js, mod-checklist.js, mod-se.js, mod-gerador.js, mod-motores.js, mod-spda.js,
  mod-nr10.js, mod-visita.js, firebase-config.js, sw.js, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png

Publicar no GitHub Pages:
 1. github.com > New repository > nome: XPA-INSPECOES > Public > Create.
 2. "uploading an existing file" > selecione os 15 arquivos > Commit changes.
 3. Settings > Pages > Source: "Deploy from a branch" > Branch: main / (root) > Save.
 4. Aguarde 1–2 min. Endereço: https://SEU-USUARIO.github.io/XPA-INSPECOES/

Instalar no celular (com internet, só na primeira vez):
 - Android (Chrome): abra o endereço > menu ⋮ > "Instalar app" / "Adicionar à tela inicial".
 - iPhone (Safari): abra o endereço > Compartilhar > "Adicionar à Tela de Início".
 - Abra o app instalado uma vez com internet e espere ~10 s (baixa os geradores de PDF/Excel).

Migrar os dados dos apps antigos (XPA-TERMOGRAGIA e XPA-SUBESTACAO):
 - No app antigo, abra cada inspeção > "Exportar backup" (arquivo .json).
 - No app novo, tela inicial > "Importar backup" > escolha o .json. Ele é convertido automaticamente.

Estrutura: index.html = núcleo (telas, armazenamento, fotos, backup, kits de PDF/Excel);
mod-checklist.js = fábrica dos módulos de checklist; cada mod-xxx.js = um tipo de trabalho.
Adicionar um módulo novo: criar mod-xxx.js, incluir <script src="mod-xxx.js"> no index.html
e acrescentar './mod-xxx.js' na lista LOCAL do sw.js. Atualizar: mudar VERSION em sw.js.

Importante: os dados ficam no aparelho. Use "Exportar backup" ao final de cada visita.

==================== LOGIN E SINCRONIZAÇÃO NA NUVEM (Firebase – opcional) ====================
Sem configurar, o app funciona como antes (dados só no aparelho). Para ativar login com e-mail e senha
e sincronizar os trabalhos entre aparelhos (gratuito no plano Spark do Firebase):

 1. Acesse https://console.firebase.google.com > "Adicionar projeto" (ex.: xpa-inspecoes). Google Analytics pode ficar desativado.
 2. Menu "Criação" > Authentication > "Começar" > guia "Sign-in method" > ative "E-mail/senha" > Salvar.
    Na guia "Users" > "Adicionar usuário": cadastre o e-mail e a senha de cada técnico.
    Em "Settings" > "Domínios autorizados" > adicione: SEU-USUARIO.github.io
 3. Menu "Criação" > Firestore Database > "Criar banco de dados" > local: southamerica-east1 (São Paulo)
    > "Iniciar no modo de produção". Depois, guia "Regras" > apague tudo e cole:

      rules_version = '2';
      service cloud.firestore {
        match /databases/{database}/documents {
          match /data/users/{uid}/{docId} {
            allow read, write: if request.auth != null && request.auth.uid == uid;
          }
        }
      }

    > Publicar. (Cada usuário só lê e grava os próprios trabalhos.)
 4. Engrenagem > "Configurações do projeto" > "Seus apps" > ícone Web (</>) > apelido "XPA Inspeções"
    > Registrar app > copie o bloco  const firebaseConfig = { apiKey: "...", ... }
 5. Abra o arquivo firebase-config.js no GitHub (lápis para editar) e substitua os valores pelos copiados.
    Commit. Em 1–2 min o app passa a pedir login.

Como funciona depois de ativado:
 - Tela de login (e-mail/senha), "Esqueci a senha" envia e-mail de redefinição.
 - "Usar sem conta" mantém o uso só no aparelho (útil sem internet no primeiro acesso).
 - Offline: o app abre com a sessão lembrada e grava no aparelho; ao voltar a internet, envia tudo (status no topo).
 - Cada técnico vê só os próprios trabalhos. Para compartilhar entre técnicos, use "Exportar/Importar backup"
   (ou peça a versão com "equipe", em que todos da empresa veem tudo).
 - Fotos ficam dentro dos documentos (limite de 1 MB por foto já respeitado pela compressão do app).

Para desativar o login: volte apiKey para "COLE_AQUI" em firebase-config.js.
